Running Drude-SILCS on Falcon
=============================

Modules to Load: GROMACS
------------------------

```
module load GCC/12.3.0
module load CUDA/12.6.0
```

Modules to Load: OpenMM
-----------------------

```
module load GCCcore/12.3.0
module load CUDA/12.6.0
module load Python/3.11.3-GCCcore-12.3.0
```
